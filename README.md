### Program Generator dan Evaluasi Latihan Soal Matematika Berbasis Python

## Deskripsi
MathQuiz adalah program Python berbasis terminal untuk menghasilkan soal matematika secara acak, memeriksa jawaban, menghitung nilai, dan menyimpan riwayat latihan pengguna.

## Fitur
- Generator 10 soal matematika secara acak.
- Operasi penjumlahan, pengurangan, perkalian,
  dan pembagian.
- Pemeriksaan jawaban otomatis.
- Perhitungan nilai akhir.
- Evaluasi hasil latihan.
- Penyimpanan riwayat latihan.

## Persyaratan
- Python 3.x
- Visual Studio Code
- Git dan GitHub

## Cara Menjalankan
Buka terminal pada folder proyek, kemudian jalankan:

python src/main.py
